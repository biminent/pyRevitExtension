# Biminent Tools (pyRevit extension)

Free productivity tools for Revit by [Biminent](https://biminent.com).

This extension is the free, community-facing tier of the Biminent product
family. Professional products (Apartment Sheets, ...) are separate C# add-ins —
see https://www.biminent.com/products.

All tools are **written from scratch** following the Biminent design language
(see [DESIGN.md](DESIGN.md)). The open-source EF-Tools and pyChilizer
extensions serve as feature references only — no code is copied from them, so
this extension carries no GPL obligation and can be licensed freely.

## Installation

You need [pyRevit](https://github.com/eirannejad/pyRevit/releases) installed.

**Option A — register the Biminent catalog (recommended).** Run once in a
terminal, then install "Biminent" from pyRevit's *Extensions* window:

```
pyrevit extensions sources add https://raw.githubusercontent.com/biminent/pyRevitExtension/main/extensions.json
```

**Option B — install directly from the repo URL:**

```
pyrevit extend ui Biminent https://github.com/biminent/pyRevitExtension.git
```

Either way, reload pyRevit (or restart Revit) and the **Biminent** tab appears
on the ribbon. Update later with `pyrevit extensions update Biminent`.

## Structure

```
Biminent.extension/
  extension.json                  pyRevit extension metadata
  DESIGN.md                       the Biminent tool design language (read first!)
  lib/
    biminent/                     shared python library (importable by all tools)
      __init__.py                 brand constants: URLs, version, colors
      ui.py                       BiminentWindow WPF base class + theme loader
    resources/theme/              Biminent WPF theme (XAML resource dictionaries)
  Biminent.tab/
    Biminent.panel/               brand panel: About window + website links
    DWG.panel/                    DWG linking workflows
    Naming.panel/                 Rename Studio (reference tool implementation)
    Review.panel/                 Purge+, Review Warnings
    Select.panel/                 Select in Scope Box, Select Similar, Select in Range
  tools/
    regen_icons.ps1               regenerate all ribbon icons in the brand gradient
```

## Icons

All ribbon icons share a teal->navy brand gradient, regenerated by
`tools/regen_icons.ps1`:

- `-Mode continuous` (default): one gradient flows across the whole ribbon
  (lightest left, darkest right). **Re-run after adding/removing/reordering any
  tool** - every icon's colour depends on its position and the total count.
- `-Mode tile`: every icon carries the full gradient on its own
  (position-independent; no re-run needed when the toolset changes).

The `$Order` list at the top of the script is the assumed left-to-right ribbon
order (pyRevit = alphabetical by folder). Reorder it there to remap the gradient.

## Theme

The XAML files in `lib/resources/theme/` are copies of
`Bofakta/src/Biminent.Shared.UI/Themes/*.xaml` (the canonical source).
`Brand.xaml` replaces `BiminentTheme.xaml`, whose `pack://` merger only works
from the compiled DLL; merging order is handled by `biminent.ui.load_theme`.

**When the shared theme changes, re-copy the files.** Do not edit them here.

## Writing a new tool

1. Create `MyTool.pushbutton/` with `script.py`, `MyToolWindow.xaml`,
   `bundle.yaml`, and `icon.png`.
2. Subclass `biminent.ui.BiminentWindow` and load your XAML.
3. In XAML, reference theme resources with `{DynamicResource ...}` only
   (the theme is merged after the XAML loads, so `StaticResource` will fail).
   Available styles: `PrimaryButtonStyle`, `AccentButtonStyle`,
   `SecondaryButtonStyle`, `GhostButtonStyle`, `HeadingSmallStyle`,
   `BodyStyle`, `CardStyle`, `ElevatedCardStyle`, `CaptionStyle`, etc. —
   see the theme XAML files for the full set.

Use `About.pushbutton` as the reference implementation.
